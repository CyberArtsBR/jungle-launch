# Character asset

Place the rigged player file here as:

`professional.glb`

The v0.4 renderer automatically loads it and normalizes its scale. If it is absent, a generated 3D fallback monkey is used.

The supplied model was inspected as a glTF 2.0 GLB with a 26-joint Mixamo-style rig, 8 materials, two embedded 1024×1024 textures, and no animation clips.
