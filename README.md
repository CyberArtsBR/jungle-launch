# Jungle Launch

Original browser physics-launch game prototype.

## Play
This repository contains the online build of **Jungle Launch v0.3.1**.

### Controls
- **Space / W / Up / left click** — start, lock angle, lock power, air boost, react to specials
- **Shift / S / Down / right click** — dive
- **P** — pause
- **R** — restart same seed
- **F2** — debug panel
- **Touch** — tap to boost, swipe down to dive

The game is implemented with HTML5 Canvas and vanilla JavaScript.
